Important: This is an aggressive profile, not a universal FPS guarantee. Review the preview on each PC. Processor boost can increase heat and fan noise. The profile does not disable Intel thermal or firmware safety protections.

How to use it

  1. Sign in to GitHub with an account that has access to the private repository.
  2. Download the ZIP package and extract all files to a folder.
  3. Double-click START-Windows-Performance.cmd.
  4. Approve the Administrator prompt and choose 1 — Preview settings.
  5. Only after reviewing the preview, choose 2 — Apply performance profile.
  6. After restarting, run the launcher again and choose Verify. Use Rollback to restore the saved baseline on that same PC.
