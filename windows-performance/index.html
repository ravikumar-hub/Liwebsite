How to use it

  1. Download the package and extract all files into one folder.
  2. Open the launcher in the extracted folder.
  3. Approve the Administrator prompt.
  4. Choose Preview settings and review the proposed changes.
  5. Choose Apply performance profile only when you are ready.
  6. After restarting, use Verify. Use Rollback to restore the original settings saved on that same PC.
