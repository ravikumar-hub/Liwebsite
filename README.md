# Linux Distros Explorer

A simple, searchable web app to browse and compare Linux distributions.

🔗 **Live site:** https://ravikumar-hub.github.io/Liwebsite/

## Features

- 🔍 Search and filter across 27+ distros (Ubuntu, Debian, Mint, Pop!_OS, Zorin, Elementary OS, etc.)
- 🗂️ Categorized by base: Debian-based, Red Hat-based, Arch-based, Independent, and Specialized
- 📋 Each distro card shows what it's based on, release cadence, and direct links to the official website and download page
- ⚡ Built with plain HTML/CSS/JS — no backend, fully static

## Who it's for

- Anyone exploring Linux distros for the first time
- Anyone comparing options before switching

## Tech Stack

- HTML
- CSS
- JavaScript

## Running locally

1. Clone the repo:https://github.com/ravikumar-hub/Liwebsite.git
2. 2. Open `index.html` in your browser — no build step or server required.
